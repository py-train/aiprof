Part 0 — What is n8n?

n8n in one paragraph

n8n (pronounced nodemation) is an open-source, self-hostable workflow automation platform. You build automations by connecting nodes on a visual canvas — each node is one action (fetch data, transform it, send an email, call an AI model, etc.). You never need to write a web server or manage infrastructure. Unlike Zapier or Make, n8n can run entirely on your own machine with full data privacy.

Core Concepts

TermWhat it meansReal-world analogy
WorkflowA named automation — a set of connected nodesA recipe
NodeOne step: a trigger or an actionOne instruction in the recipe
Trigger nodeStarts the workflow (schedule, webhook, manual click)The alarm clock
Action nodeDoes something: HTTP call, send email, run codeAdding an ingredient
ConnectionArrow passing data from one node to the nextPassing the bowl to the next chef
ExecutionOne run of the workflow from trigger to endCooking one batch

Part 1 — Install n8n on Ubuntu with Docker

You need Ubuntu 20.04 LTS or later (physical machine, VM, or WSL2). All commands run in a terminal. Estimated time: 15 minutes.
1
Update the system and install prerequisites
📋 Copy & paste into terminal
sudo apt update && sudo apt upgrade -y
sudo apt install -y ca-certificates curl gnupg lsb-release
2
Install Docker Engine
📋 Copy & paste the full block into terminal
# Add Docker's official GPG key
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

# Add Docker repository
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Install Docker
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io \
                    docker-buildx-plugin docker-compose-plugin

# Allow current user to run Docker without sudo
sudo usermod -aG docker $USER
newgrp docker
✅ Verify Docker is installed
docker --version
# Expected output: Docker version 25.x.x or later
3
Create a persistent volume and start n8n
📋 Copy & paste into terminal
# Create a Docker volume so workflows survive container restarts
docker volume create n8n_data

# Start n8n — downloads the image automatically (~200 MB, one-time only)
docker run -d \
  --name n8n \
  --restart unless-stopped \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e N8N_SECURE_COOKIE=false \
  docker.n8n.io/n8nio/n8n
The -e N8N_SECURE_COOKIE=false flag is required for local HTTP access. Remove it only for HTTPS production deployments.
✅ Confirm the container is running
docker ps
# You should see n8n listed with STATUS "Up"

# Optional: view live logs
docker logs n8n --tail 30
4
Open n8n in your browser
🖱 UI Action
  • Open Firefox or Chrome on the Ubuntu machine
  • Navigate to http://localhost:5678
  • Complete the one-time setup form: enter your name, email, and a password
  • Click Get started — you are now inside n8n!
If you are on a remote Ubuntu server, replace localhost with the server IP address. Open the firewall port first: sudo ufw allow 5678

Step B1 — Create workflow and add Webhook trigger

🖱 UI Action

  • Click Add first step → search Webhook → select it
  • In the Webhook node panel, set HTTP Method = POST
  • Set Response Mode = Using Respond to Webhook Node
  • Note the Test URL shown — copy it (you will use it in Step B4)
  • Click Back to canvas

Step B2 — Add IF node for branching logic

🖱 UI Action
  • Click + on the Webhook node → search IF → select it
  • In the IF node, configure Condition 1:
SettingValue
Value 1Click field → toggle Expression → paste: {{ $json.body.score }}
OperationGreater than or equal to
Value 270 (type directly — no expression needed)
🖱 Continue
  • Click Back to canvas

Step B3 — Add Code nodes for each branch

🖱 UI Action — True branch (score ≥ 70)
  • Click the true output connector on the IF node → click +
  • Search Code → select it
  • Double-click the node title and rename it Pass Message
  • Make sure Language = JavaScript
  • Clear all existing code in the editor, then paste the code below
📋 Paste into the Pass Message Code node
// Access the data that came in from the webhook body
const score = $input.first().json.body.score;
const name  = $input.first().json.body.name || "Candidate";

// Build a structured result object
const result = {
  status   : "PASS",
  name     : name,
  score    : score,
  grade    : score >= 90 ? "A" : score >= 80 ? "B" : "C",
  message  : `Congratulations ${name}! You scored ${score}/100. Result: PASS.`,
  timestamp: new Date().toISOString()
};

// n8n Code nodes must return an array of items
return [{ json: result }];
🖱 UI Action — False branch (score < 70)
  • Click Back to canvas
  • Click the false output connector on the IF node → click +
  • Search Code → select it → rename it Fail Message
  • Clear the editor and paste the code below
📋 Paste into the Fail Message Code node
// Access the data from the webhook body
const score = $input.first().json.body.score;
const name  = $input.first().json.body.name || "Candidate";

// Calculate how many marks short of passing
const gap = 70 - score;

const result = {
  status   : "FAIL",
  name     : name,
  score    : score,
  grade    : "F",
  message  : `Sorry ${name}, you scored ${score}/100. You need ${gap} more marks to pass.`,
  timestamp: new Date().toISOString()
};

return [{ json: result }];

Step B3b — Add Respond to Webhook nodes

🖱 UI Action — do this for BOTH Code nodes
  • Click + after Pass Message → search Respond to Webhook → select it
  • Set Respond With = First Incoming Item's JSON
  • Click Back to canvas
  • Repeat the same steps after Fail Message
  • Press Ctrl+S to save

Step B4 — Test with curl from the terminal

🖱 UI Action first — activate the listener
  • Click the Webhook node → click Listen for test event
  • The status changes to "Waiting for webhook call…"
  • Now open a new terminal window
📋 Paste these curl commands into the new terminal — replace <WEBHOOK-ID> with yours
# Test 1: Passing score (score >= 70)
curl -X POST http://localhost:5678/webhook-test/<WEBHOOK-ID> \
  -H "Content-Type: application/json" \
  -d '{"name": "Priya Sharma", "score": 85}'

# Test 2: Failing score (score < 70)
curl -X POST http://localhost:5678/webhook-test/<WEBHOOK-ID> \
  -H "Content-Type: application/json" \
  -d '{"name": "Rahul Gupta", "score": 55}'

# Test 3: Perfect score
curl -X POST http://localhost:5678/webhook-test/<WEBHOOK-ID> \
  -H "Content-Type: application/json" \
  -d '{"name": "Ayesha Khan", "score": 95}'
The full Test URL is shown in the Webhook node panel. It looks like: http://localhost:5678/webhook-test/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx — copy the UUID at the end.
Watch the n8n canvas as you run curl — nodes light up green as each one executes. Click any lit node to inspect the exact data that passed through it.

Workflow C — Scheduled AI-Powered Summary Report

Goal: Every day at 8 AM, fetch trending tech data, send it to OpenAI for a plain-English summary, and display the report. Introduces: Schedule Trigger, secure Credentials, OpenAI API call, chained HTTP nodes.

TriggerSchedule (8 AM)
→
HTTPFetch Headlines
→
CodeBuild AI Prompt
→
HTTPCall OpenAI API
→
SetFormat Report
Workflow C requires an OpenAI API key. If you do not have one, you can still follow all steps and substitute the OpenAI call with any other free API.

Step C0 — Store your OpenAI API key securely

🖱 UI Action — n8n Credentials (encrypted storage)
  • Left sidebar → Settings → Credentials → click + Add credential
  • Search Header Auth → select it
  • Name the credential: OpenAI-Bearer-Key
  • Name field: Authorization
  • Value field: Bearer sk-your-openai-api-key-here
  • Click Save
Never paste your API key directly into a URL or Code node field. Always use n8n Credentials — they are AES-256 encrypted at rest and masked in logs.

Step C1 — Create workflow and add Schedule Trigger

🖱 UI Action
  • Click + New Workflow → rename it Daily AI News Brief
  • Add first step → search Schedule Trigger → select it
  • Set Trigger Interval = Days
  • Set Trigger at Hour = 8 and Minute = 0
  • Click Back to canvas

Step C2 — Fetch trending tech headlines (no API key needed)

🖱 UI Action
  • Click + → search HTTP Request → select it
  • Rename node to Fetch HackerNews IDs
  • Method = GET → paste the URL below
📋 Paste this URL
https://hacker-news.firebaseio.com/v0/topstories.json?limitToFirst=5&orderBy=%22$key%22
🖱 Continue
  • Click Test step — you should see an array of 5 story IDs
  • Click Back to canvas

Step C3 — Build the AI prompt in a Code node

🖱 UI Action
  • Click + → search Code → select it → rename to Build Prompt
  • Clear the code editor and paste the code below
📋 Paste into Build Prompt Code node
// Collect story IDs from the previous HTTP node
const storyIds = $input.all().map(item => item.json);
const idList   = storyIds.slice(0, 5).join(", ");

// Compose the prompt we will send to OpenAI
const prompt = `You are a helpful technology analyst writing for business professionals.

The top 5 trending story IDs on Hacker News right now are: ${idList}.

Hacker News is a technology and startup news aggregator widely read by developers,
founders, and business leaders. Based on the context that these are currently
the most upvoted stories, please:

1. Write a 3-sentence summary of what types of topics are likely trending
   in the global technology community today.
2. Suggest 2 strategic questions a senior business professional at a consulting
   firm might want to explore based on today's technology trends.
3. Rate the overall market sentiment (Bullish / Neutral / Cautious) and explain why in one sentence.

Keep your response professional, concise, and insightful.`;

// Return structured output for the next node
return [{
  json: {
    prompt      : prompt,
    story_ids   : storyIds.slice(0, 5),
    generated_at: new Date().toISOString()
  }
}];

Step C4 — Call the OpenAI API

🖱 UI Action
  • Click + → search HTTP Request → select it → rename to Call OpenAI
  • Method = POST → paste URL below
📋 Paste this URL
https://api.openai.com/v1/chat/completions
🖱 UI Action — authentication
  • Scroll to Authentication → select Predefined Credential Type
  • Credential type = Header Auth
  • Credential = select OpenAI-Bearer-Key (the one you saved earlier)
🖱 UI Action — request body
  • Toggle Send Body = ON
  • Body Content Type = JSON
  • Click Using JSON tab and paste the body below
📋 Paste this JSON body — the expression pulls the prompt from the previous node
{
  "model": "gpt-4o-mini",
  "messages": [
    {
      "role": "user",
      "content": "={{ $json.prompt }}"
    }
  ],
  "temperature": 0.5,
  "max_tokens": 500
}
🖱 Continue
  • Click Back to canvas

Step C5 — Extract the AI response with a Set node

🖱 UI Action
  • Click + → search Set → select it → rename to Format Report
  • Add two fields using Expression mode (fx) for values:
📋 Set node field values — toggle Expression (fx) for each
# Field 1
Name  : ai_summary
Type  : String
Value : {{ $json.choices[0].message.content }}

# Field 2
Name  : report_date
Type  : String
Value : {{ new Date().toLocaleDateString('en-IN', { dateStyle: 'full' }) }}
🖱 Final steps
  • Click Back to canvas
  • Press Ctrl+S to save
  • Click ▶ Test workflow to run it manually right now
  • Click the Format Report node to read the AI-generated summary
  • Toggle the Active switch (top right) to enable automatic daily runs at 8 AM

Part 3 — Export, Import & Share Workflows

Export a workflow as JSON

🖱 UI Action
  • Open any workflow you built
  • Click the workflow name at the top-left → ⋯ More options → Export
  • A .json file downloads to your machine
  • Open it in any text editor — you will see the full workflow definition (nodes, connections, settings)

Import a workflow from JSON

🖱 UI Action
  • Left sidebar → Workflows → click the + button
  • Select Import from file
  • Choose the workflow_a_weather.json or workflow_b_score.json file provided with this lab
  • n8n recreates the full workflow — re-link credentials if prompted

Manage the n8n container

📋 Terminal — container management commands
# Stop n8n (all data is preserved in the Docker volume)
docker stop n8n

# Restart n8n any time
docker start n8n

# Update to the latest n8n version
docker stop n8n
docker rm n8n
docker pull docker.n8n.io/n8nio/n8n
docker run -d --name n8n --restart unless-stopped \
  -p 5678:5678 -v n8n_data:/home/node/.n8n \
  -e N8N_SECURE_COOKIE=false docker.n8n.io/n8nio/n8n
