Before you start

How to teach expressions clearly

Many beginners struggle not because the logic is hard, but because they are unsure where expressions belong. In these exercises, every place that needs dynamic values is called out explicitly with both the click path and the final expression.

Use the expression toggle

In any text field, click the field, then choose Add Expression or switch the field into expression mode when n8n offers it.

Prefer the variable picker first

Use the dropdown or variable selector to insert fields from the current item, then inspect the generated expression instead of typing everything from memory.

Use Code nodes sparingly

If a Set, Edit Fields, IF, or Switch node can do the job, prefer that first. Use JavaScript only when transformation logic becomes awkward in expressions.

Exercise 1

Hello workflow builder

This first workflow teaches the canvas, execution flow, node outputs, and the idea that n8n passes JSON from one node to the next. It is intentionally simple and should take only a few minutes.
Difficulty: Beginner Nodes: Manual Trigger, Edit Fields Concepts: JSON, expressions
Outcome

Create a workflow that stores a participant name, topic, and audience level, then builds one dynamic summary sentence.

Node sequence

1
Manual Trigger

Add a Manual Trigger node so participants can run the workflow from the editor.

2
Edit Fields (or Set)

Add fields named name, topic, and audience_level.

3
Add one more field

Create a dynamic field called message that combines the earlier values into one sentence using an expression.

Suggested sample values

  • name = Ashish
  • topic = n8n fundamentals
  • audience_level = beginner

Run the workflow once and inspect the output JSON in the Edit Fields node result pane.

Expression instructions

  1. In the message field, click into the value box.
  2. Choose Add Expression.
  3. In the expression editor, use the variable picker to insert name, topic, and audience_level from the current item.
  4. Wrap them in normal text to build one final sentence.

Final expression

{{ 'Participant ' + $json.name + ' is exploring ' + $json.topic + ' at ' + $json.audience_level + ' level.' }}

What to explain while teaching

  • The workflow data is a JSON object flowing between nodes.
  • $json.field_name means “read the current item’s field value”.
  • Expressions are useful when a value is partly fixed text and partly dynamic data.
Exercise 2

Workshop registration processor

This lab introduces more realistic incoming data and a branch. Participants practice reading fields from JSON and routing the flow based on one condition.
Difficulty: Beginner+ Nodes: Manual Trigger, Edit Fields, IF Concepts: field mapping, conditions
Outcome

Simulate a learner registration record and route beginners and advanced users differently.

Suggested node sequence

  1. Manual Trigger
  2. Edit Fields to create: name, email, experience_level, interest_area
  3. IF node to check whether the learner is a beginner
  4. Edit Fields on the true branch to create a beginner guidance message
  5. Edit Fields on the false branch to create an advanced guidance message

Sample values

  • name = Riya
  • email = riya@example.com
  • experience_level = beginner
  • interest_area = AI automation

How to configure the IF node

  1. Open the IF node.
  2. For the left value, click the field and choose the current item variable for experience_level.
  3. Keep the operator as is equal to.
  4. For the right value, type beginner.

This is often easier for participants than writing a raw condition expression from scratch.

Equivalent expression they should recognize

{{ $json.experience_level }}

If you want, you can show that the IF node is visually building logic around this field value.

Beginner branch message expression

{{ 'Welcome ' + $json.name + '. Start with the fundamentals track for ' + $json.interest_area + '.' }}

Advanced branch message expression

{{ 'Welcome ' + $json.name + '. You can directly try the advanced labs in ' + $json.interest_area + '.' }}

What to explain while teaching

  • Most business workflows have a decision point, and IF is often the first routing node to learn.
  • n8n conditions can usually be built visually, which reduces syntax anxiety for beginners.
  • Expressions are still useful on each branch to personalize outputs.
Exercise 3

AI summary helper with cleanup logic

This lab introduces an AI step and a small amount of JavaScript. Participants first send messy notes to an AI model, then use a Code node to clean and structure the result.
Difficulty: Intermediate Nodes: Manual Trigger, Edit Fields, OpenAI/AI node, Code Concepts: prompts, expressions, JavaScript
Outcome

Turn rough workshop notes into a polished summary and then reshape the AI output in a Code node.

Suggested node sequence

  1. Manual Trigger
  2. Edit Fields with one text field named raw_notes
  3. OpenAI or AI text-generation node
  4. Code node to format the result into cleaner JSON

Sample raw notes

Use a short, messy paragraph such as:

team discussed using n8n for support triage, email drafting and lead qualification. people want simple examples first. also need guardrails before production.

Prompt field instructions

  1. In the AI node prompt or user message field, switch to expression mode if needed.
  2. Type fixed instruction text first.
  3. Use the variable picker to insert the current item field raw_notes.
  4. Ask for short structured output.

Prompt expression

{{ 'Rewrite the following workshop notes into 3 bullet points and one final action item:\n\n' + $json.raw_notes }}

Code node instructions

Set the Code node to run once for each item if your setup asks for an execution mode. Then paste the following JavaScript into the main code field.

const aiText = $json.text || $json.output || $json.response || '';

return [
  {
    json: {
      original_notes: $json.raw_notes || '',
      cleaned_summary: aiText.trim(),
      status: 'ready_for_review',
      word_count: aiText.trim() ? aiText.trim().split(/\s+/).length : 0,
    },
  },
];

What to explain while teaching

  • The AI node is just another step in a larger workflow, not the workflow by itself.
  • The Code node is useful when you want complete control over the final JSON shape.
  • The line that reads $json.text || $json.output || $json.response is defensive programming because different AI nodes or configurations may expose output fields differently.
Exercise 4

Importable AI ticket triage workflow

This final exercise gives participants a complete workflow they can import. It demonstrates a realistic pattern: intake data, generate a category, normalize it, branch, and prepare a response.
Difficulty: Intermediate+ Includes workflow JSON file Pattern: input → enrich → decide → act
Workflow goal

A new support request comes in with customer text. AI suggests a ticket category, a Code node normalizes it, and routing prepares the correct downstream message.

Suggested flow structure

StepNodePurpose
1Manual TriggerRun the demo inside the editor.
2Edit FieldsCreate a sample ticket with customer name, email, priority, and issue text.
3OpenAI / AI nodeClassify the issue into one of a few allowed categories.
4Code nodeNormalize the AI output to a predictable lowercase category.
5Switch or IF nodesRoute billing, technical, and general questions differently.
6Edit FieldsPrepare the final response message.

How to import the workflow

  1. Download the JSON file linked at the top of this page.
  2. Open your n8n editor.
  3. Use the workflow import option in the editor to import from file or paste JSON.
  4. Open the imported workflow and inspect each node before running it.

What participants should modify

  • Change the sample ticket text and see if routing changes.
  • Add one more category such as access or refund.
  • Replace the final message with an email draft or Slack-ready output.

Normalization Code node snippet used in the workflow

const raw = ($json.text || $json.output || $json.category || '').toLowerCase();

let normalized = 'general';

if (raw.includes('billing')) {
  normalized = 'billing';
} else if (raw.includes('technical') || raw.includes('bug') || raw.includes('error')) {
  normalized = 'technical';
} else if (raw.includes('account') || raw.includes('login') || raw.includes('access')) {
  normalized = 'account';
}

return [
  {
    json: {
      ...$json,
      normalized_category: normalized,
    },
  },
];
Teaching notes

Suggested facilitation pattern

To keep the session interactive, first demonstrate each workflow once, then ask participants to reproduce it, and finally ask them to modify one field or node before moving on.

Keep the first run guided

For each exercise, ask participants to execute the workflow once before editing anything. This helps them understand the baseline output.

Make one controlled change

Ask them to change only one field first, such as the audience level, ticket text, or prompt wording, and then rerun the workflow.

Reflect on patterns

At the end, point out that most automation patterns repeat the same ideas: capture input, transform data, branch on logic, and produce an action or response.
