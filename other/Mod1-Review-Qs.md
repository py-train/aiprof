## Multiple Choice Questions (Choose BEST answer)

Q1. What is the MAIN difference between AI and Machine Learning?
A) AI requires human intervention, ML is fully automated
B) ML is a subset of AI that learns patterns from data
C) AI uses only supervised learning, ML uses unsupervised
D) ML creates new algorithms, AI applies existing ones

Answer: B) ML is a subset of AI that learns patterns from data

Q2. In the ML workflow, what happens immediately AFTER training the model?
A) Collect more training data
B) Make predictions on test data
C) Deploy to production
D) Perform feature engineering

Answer: B) Make predictions on test data

Q3. Which ML category would you use for customer segmentation without labels?
A) Supervised Learning
B) Reinforcement Learning  
C) Unsupervised Learning
D) Transfer Learning

Answer: C) Unsupervised Learning

---

## True/False (Explain your answer)

Q4. Overfitting occurs when a model performs well on training data but poorly on unseen test data.
TRUE / FALSE: ______
Explanation: ________________________________________________

Answer: TRUE
Explanation: Overfitting = memorizes training data (high training accuracy, low test accuracy)

Q5. In supervised learning, the algorithm needs labeled training data.
TRUE / FALSE: ______
Explanation: ________________________________________________

Answer: TRUE
Explanation: Labeled data = inputs + correct outputs for learning
