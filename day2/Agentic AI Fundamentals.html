Traditional AI vs Agentic AI

Traditional AI

Single-turn responses, no memory, task-specific

What is Agentic AI?

Autonomous Systems That Pursue Goals

  • Autonomy: Operate with minimal human oversight
  • Goal-Oriented: Pursue specific objectives
  • Adaptive: Learn and adjust from feedback
  • Tool Use: Call APIs, search, execute code

Key Characteristics of AI Agents

  • Planning: Break complex tasks into subtasks
  • Reasoning: Evaluate options and consequences
  • Memory: Retain context across interactions
  • Reflection: Self-critique and improve

Agent Architecture Components

The Building Blocks

  • LLM Brain: Core reasoning engine (GPT-4, Claude)
  • Tools/Actions: Functions agent can call
  • Memory: Short-term (chat) + long-term (vector DB)
  • Orchestrator: Coordinates loop execution

The Agent Loop

Perceive → Reason → Act → Observe

Continuous cycle until goal achieved

Step 1: Perception

Understanding the Environment

  • Receive user query or system state
  • Load relevant context from memory
  • Gather available tool/action options
  • Build current state representation

Step 2: Reasoning

Deciding What to Do Next

  • LLM evaluates current state and goal
  • Considers which tool to use (if any)
  • Plans next action with arguments
  • May generate intermediate "thoughts"

Step 3: Action

Executing Decisions

  • Call selected tool with parameters
  • Execute function (API call, DB query, search)
  • Or: return final answer to user

Step 4: Observation

Learning from Results

  • Receive tool output or error
  • Add observation to agent's context
  • Decide: loop again or finish?
  • Update memory with new information

Agent Loop in Action

User: "Book a flight to NYC for next Monday"

Cycle 1:
  Reason: Need to search flights
  Act: search_flights(destination="NYC", date="2026-02-10")
  Observe: Found 3 options, prices $200-$350

Cycle 2:
  Reason: Ask user preference or pick cheapest
  Act: ask_user("3 flights found. Cheapest at $200?")
  Observe: User says "yes"

Cycle 3:
  Reason: Book the flight
  Act: book_flight(flight_id="AA123", price=200)
  Observe: Booking confirmed, ID=XYZ789
  
Final: "Flight booked! Confirmation: XYZ789"

Tool/Function Calling

How Agents Use External Capabilities

  • Define tools with name, description, parameters
  • LLM decides when to call which tool
  • Returns structured JSON with function + args
  • Orchestrator executes and returns result

Tool Definition Example

tools = [
  {
    "name": "search_web",
    "description": "Search the web for current information",
    "parameters": {
      "type": "object",
      "properties": {
        "query": {
          "type": "string",
          "description": "Search query"
        }
      },
      "required": ["query"]
    }
  }
]

# LLM output:
{
  "tool": "search_web",
  "arguments": {"query": "2026 AI trends"}
}

Agent Pattern: ReAct

Reason + Act Framework

  • Thought: Agent explains its reasoning
  • Action: Tool call with arguments
  • Observation: Tool result
  • Loop continues with explicit reasoning traces

ReAct Example

Question: "What's the weather in Tokyo?"

Thought: I need to search for current weather in Tokyo.
Action: search_web("Tokyo weather today")
Observation: Partly cloudy, 15°C, humidity 60%

Thought: I have the weather data, can answer now.
Action: Final Answer
Answer: "Tokyo is currently partly cloudy at 15°C 
         with 60% humidity."

Explicit reasoning makes debugging easier

Agent Pattern: Reflection

Self-Critique & Improvement

  • Agent generates initial answer
  • Reflects: "Is this correct? Complete?"
  • Identifies weaknesses or gaps
  • Iterates to improve response quality

Agent Pattern: Planning

Decompose Before Executing

  • Break complex goal into subtasks
  • Create ordered plan of actions
  • Execute plan step-by-step
  • Adapt plan if steps fail

Planning Example

Goal: "Research and summarize recent AI papers"

Plan:
1. Search for "AI research papers 2026"
2. Extract top 5 paper titles and abstracts
3. Summarize each paper in 2 sentences
4. Compile into final report

Execute:
Step 1: search_web("AI research papers 2026")
  → Found 10 papers
Step 2: extract_metadata(papers[:5])
  → Got titles + abstracts
Step 3: For each paper, summarize...
Step 4: Compile final report

LangChain Agent Example

from langchain.agents import initialize_agent, Tool
from langchain.chat_models import ChatOpenAI

tools = [
  Tool(name="Search", func=search_web, 
       description="Search the web"),
  Tool(name="Calculator", func=calculate,
       description="Do math")
]

llm = ChatOpenAI(model="gpt-4o")
agent = initialize_agent(
  tools, llm, agent_type="zero-shot-react-description"
)

response = agent.run("What's 15% of 2500 plus Tokyo's temp?")
print(response)

Challenges in Agentic AI

  • Reliability: Agents can fail or loop infinitely
  • Cost: Many LLM calls per task
  • Latency: Multi-step reasoning takes time
  • Safety: Agents need guardrails

Agent Design Best Practices

  • Clear Tools: Descriptive names & docs
  • Max Steps: Limit loop iterations
  • Error Handling: Graceful fallbacks
  • Logging: Track reasoning traces

Evaluating Agent Performance

  • Success Rate: Did it complete the task?
  • Efficiency: Steps taken vs optimal path
  • Answer Quality: Accuracy, relevance
  • Cost: Tokens used, API calls
