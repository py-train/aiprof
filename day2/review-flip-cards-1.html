MCQ
Easy
1. What is the most accurate description of a Large Language Model?
A. A database containing every document used during training
B. A rules engine that applies predefined legal and business logic
C. A model trained to identify and generate patterns in language
D. A search engine that always retrieves verified information
Answer
C.
LLMs learn patterns in language and generate likely sequences based on those patterns. They are not simply document databases or guaranteed fact-checking systems.
MCQ
Easy
2. During the pre-training of an LLM, the model primarily learns to:
A. Predict likely tokens or pieces of text based on surrounding context
B. Memorize every training document exactly as it appears
C. Follow organizational policies without needing additional instructions
D. Verify the truth of every statement in its training data
Answer
A.
A central pre-training objective is next-token prediction. The model learns statistical relationships among tokens and sequences.
MCQ
Easy
3. Which statement best describes the relationship between training data and an LLM’s knowledge?
A. Everything in the training data is stored as directly searchable documents
B. The model learns statistical patterns from the training data rather than retaining a perfect document library
C. The model automatically updates its knowledge whenever a new event occurs
D. Training data guarantees that the model’s responses will be factually correct
Answer
B.
Model parameters encode learned patterns. The model does not function like a perfect, directly searchable copy of every training document.
MCQ
Easy
4. What is a token?
A. A complete paragraph used by an LLM to understand a document
B. A security credential used to access an AI application
C. A fixed-size word that is identical across all languages and models
D. A unit of text processed by a language model, which may be a word, part of a word, punctuation, or a symbol
Answer
D.
Tokens may represent complete words, word fragments, punctuation, spaces, or symbols. Tokenization varies by model and language.
MCQ
Easy
5. Why does token count matter when working with an LLM?
A. It determines whether the model can process the input and generate an output within its context limit
B. It determines whether the model has access to the internet
C. It directly measures whether the answer is legally accurate
D. It guarantees that longer prompts will produce better answers
Answer
A.
Token count affects whether the request fits within the model’s context window and how much output can be generated.
MCQ
Easy
6. What is the best description of a model’s context window?
A. The model’s entire training dataset
B. The maximum amount of input and output information the model can consider in one interaction
C. The time period during which the model remains logged into an application
D. The number of users who can access the model simultaneously
Answer
B.
The context window is the information available to the model for a particular interaction. It is not the same as the model’s total training data.

7. A user pastes a very long contract into a chat and asks the model to compare the indemnity clause with a clause mentioned near the beginning. The model gives a vague answer. Which explanation is most plausible?
A. LLMs cannot process legal language
B. The model may have difficulty locating or consistently attending to relevant information in a long context
C. The model has converted the contract into a spreadsheet
D. The model has automatically replaced the indemnity clause with a standard clause
Answer
B.
Long contexts can make it harder for a model to consistently identify and use the most relevant information. Context should be structured and managed deliberately.

8. Which prompt is likely to produce the most useful contract-risk summary?
A. “Review this.”
B. “Tell me everything important.”
C. “You are a legal operations analyst. Identify limitation of liability, indemnity, termination, governing law, and data-protection provisions. For each, quote the relevant text, explain the business risk, assign High/Medium/Low risk, and state when the evidence is insufficient.”
D. “Summarize this contract perfectly with no mistakes.”
Answer
C.
This prompt defines the role, task, scope, criteria, output format, and uncertainty requirement. It is more useful than a vague request or an unrealistic demand for perfection.

9. What is the primary purpose of assigning a role in a prompt?
A. To guarantee that the model will produce an expert-level answer
B. To give the model useful perspective, priorities, and style for the task
C. To increase the model’s context window
D. To prevent the model from generating any incorrect information
Answer
B.
A role can guide perspective and priorities, but it does not guarantee expertise, correctness, or professional authorization.

10. Which prompt element most directly helps control the required output format?
A. Asking the model to “think harder”
B. Mentioning that the task is urgent
C. Providing a requested structure, such as a table with named columns
D. Increasing the number of adjectives in the prompt
Answer
C.
Explicit structures such as tables, headings, fields, or JSON-style schemas can make outputs more consistent and easier to review.
MCQ
Easy
11. What is the main benefit of providing examples in a prompt?
A. Examples can demonstrate the desired task, style, classification, or output format
B. Examples permanently retrain the underlying model
C. Examples guarantee that the model will follow all future instructions
D. Examples eliminate the need to verify the output
Answer
A.
Examples demonstrate what a good input-output relationship looks like. They guide the model but do not retrain it permanently.

12. In a multi-turn conversation, the model’s response to a later question may be influenced by:
A. Only the last sentence typed by the user
B. The conversation context made available to the model, including earlier messages
C. Every conversation ever held by every user
D. The model’s ability to remember all facts permanently
Answer
B.
The model may use the conversation history that is included in the current context. This is not equivalent to permanent human-like memory.

A. The model becomes emotionally tired
B. Earlier information may be truncated, diluted, overlooked, or confused with newer instructions

Answer
B.
Long conversations can exceed context limits or make important instructions harder to retrieve and apply consistently.

27. True or False: An LLM’s ability to produce fluent language is evidence that every factual claim in its answer is correct.
Answer
False.
Fluency measures how naturally the response is expressed, not whether the underlying claims are true.

Easy
28. True or False: A prompt can improve the relevance and consistency of an answer, but it cannot guarantee factual accuracy.
Answer
True.
Prompting can make a task clearer and improve consistency, but inaccurate source material, model limitations, ambiguity, and unsupported generation can still lead to errors.
True/False
Easy
29. True or False: Increasing the amount of context always improves an LLM’s answer.
Answer
False.
Additional context can help when it is relevant and well organized. Irrelevant, contradictory, or excessive context can reduce clarity and make retrieval of important details more difficult.

Easy
30. True or False: A model may answer differently when given the same prompt at different times or under different settings.
Answer
True.
Variations can result from model settings, sampling, system changes, conversation context, or other implementation factors.

31. True or False: Every AI system that generates text should be considered an autonomous agent.
Answer
False.
A text-generation assistant may simply respond to prompts. An agent generally involves goal-directed planning, multiple steps, tool use, or action execution.

33. “If an LLM has read a document during training, it can reproduce the document perfectly whenever asked.”
Answer
Myth.
Training does not mean the model has a perfect, user-accessible copy of every document. It learns patterns, and its ability to reproduce information may be incomplete or inaccurate.

34. “A well-designed prompt can reduce ambiguity and improve output quality, but it does not replace source verification or human judgment.”
Answer
Fact.
Prompting is an important control for task clarity and output structure, but it does not eliminate hallucinations or the need for verification.
Myth/Fact

35. “An agentic workflow should be allowed to make irreversible legal or business decisions without approval because the workflow is automated.”
Answer
Myth.
Agentic systems should operate within defined permissions, escalation rules, auditability requirements, and human approval checkpoints—especially for irreversible or high-impact actions.
