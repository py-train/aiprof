Why RAG Exists

Limitations of Pure Prompting

  • Knowledge cutoff: LLMs frozen in training time
  • Hallucinations: No grounding = invented facts
  • Private data: Can't access internal documents
  • Cost: Fine-tuning expensive vs retrieval

The RAG Solution

Retrieve First, Then Generate

  • Query → Fetch relevant docs → Inject into prompt
  • LLM answers based on provided context
  • Grounded responses with citations
  • Real-time knowledge without retraining

RAG Architecture Overview

Document ingestion → Embeddings → Vector DB → Retrieval → Generation

RAG Data Pipeline (Indexing)

Offline: Prepare Your Knowledge Base

  • 1. Ingestion: Load documents (PDFs, HTML, text)
  • 2. Chunking: Split into manageable pieces
  • 3. Embedding: Convert chunks to vectors
  • 4. Indexing: Store in vector database

Step 1: Ingestion

Loading Documents

  • Sources: PDFs, Word docs, Markdown, HTML, APIs
  • Tools: LangChain loaders, Unstructured.io, PyPDF
  • Extract: Raw text, preserve metadata (page, title)

Step 2: Chunking Strategies

How to Split Documents

  • Fixed-size: 500-1000 chars, simple but breaks context
  • Semantic: Split by paragraphs, sections (better)
  • Hierarchical: Parent-child chunks for multi-scale

Chunking Visualization

Overlap ensures context continuity across chunks

Chunking Code Example

from langchain.text_splitter import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
  chunk_size=1000,
  chunk_overlap=200,
  separators=["\n\n", "\n", " ", ""]
)

chunks = splitter.split_documents(documents)
print(f"Created {len(chunks)} chunks")

Overlap preserves context between adjacent chunks

Step 3: Embeddings

Text → High-Dimensional Vectors

  • Definition: Numerical representations capturing meaning
  • Dimension: 384 to 3072 dimensions typical
  • Property: Similar meaning → Similar vectors
  • Example: "dog" & "puppy" close, "dog" & "car" far

Popular Embedding Models (2026)

OpenAI text-embedding-3

3072 dims, $0.02/1M tokens

Cohere Embed v3

1024 dims, rerank-ready

Mistral Embed

1024 dims, 77.8% accuracy

Open-source: BGE-M3, E5-Mistral, Voyage-lite

Creating Embeddings (Code)

from langchain.embeddings import OpenAIEmbeddings

embeddings_model = OpenAIEmbeddings(
  model="text-embedding-3-small"
)

# Embed single text
vector = embeddings_model.embed_query("AI agents")
print(f"Vector dims: {len(vector)}")  # 1536

# Embed documents batch
doc_vectors = embeddings_model.embed_documents(chunks)

Vector Similarity

Finding "Close" Vectors = Semantic Match

  • Cosine Similarity: Angle between vectors (0 to 1)
  • Euclidean Distance: Straight-line distance
  • Dot Product: Magnitude + direction

Cosine Similarity Visualization

Smaller angle = higher similarity (0° = identical, 90° = unrelated)

Vector Similarity Search

Query vector finds nearest neighbors in high-dimensional space

ChromaDB: Store & Query

from langchain.vectorstores import Chroma

vectorstore = Chroma.from_documents(
  documents=chunks,
  embedding=embeddings_model,
  collection_name="docs"
)

# Query for top 3 results
results = vectorstore.similarity_search(
  "What is RAG?", k=3
)
print(results[0].page_content)

Retrieval Phase (Query Time)

Online: Answering User Questions

  • 1. Embed Query: Convert question to vector
  • 2. Search: Find top-k similar chunks
  • 3. Inject Context: Add chunks to prompt
  • 4. Generate: LLM answers with grounding

Similarity Search Types

Beyond Basic Vector Search

  • Vector-only: Pure semantic similarity
  • Hybrid (BM25 + Vector): Keyword + semantic
  • Metadata Filtering: Filter by date, source first
  • Re-ranking: Cohere rerank for precision

Hybrid Search Example

from langchain.retrievers import EnsembleRetriever
from langchain.retrievers import BM25Retriever

# Vector retriever
vector_retriever = vectorstore.as_retriever(k=5)

# Keyword retriever
bm25_retriever = BM25Retriever.from_documents(chunks)

# Combine both
ensemble = EnsembleRetriever(
  retrievers=[vector_retriever, bm25_retriever],
  weights=[0.5, 0.5]
)

RAG & Context Windows

How RAG Extends Model Memory

  • Problem: LLM context limited (4K-2M tokens)
  • RAG Solution: Retrieve only relevant chunks
  • Efficiency: 3-5 chunks (3K tokens) vs entire corpus
  • Trade-off: Retrieval accuracy vs context size

RAG Context Injection

Retrieved chunks fill context window efficiently

Complete RAG Chain (Code)

from langchain.chains import RetrievalQA
from langchain.chat_models import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

qa_chain = RetrievalQA.from_chain_type(
  llm=llm,
  retriever=vectorstore.as_retriever(k=3),
  return_source_documents=True
)

response = qa_chain("Explain RAG architecture")
print(response['result'])
print(f"Sources: {len(response['source_documents'])}")

Query → Retrieval → Answer Traceability

  • Track Sources: Which chunks were used?
  • Citations: Return page numbers, URLs
  • Confidence: Similarity scores reveal relevance
  • Debugging: Inspect retrieved context quality

Advanced RAG Techniques

  • Query Expansion: Generate multiple query variants
  • Hypothetical Document: LLM generates ideal doc, search for it
  • Parent-Child Chunks: Retrieve small, inject large
  • Adaptive Retrieval: Fetch more if answer uncertain

RAG Challenges & Solutions
